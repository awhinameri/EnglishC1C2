# Cuaderno de inglés C1–C2

Cuaderno de estudio personal organizado por temas: vocabulario, collocations, phrasal verbs, idioms, word formation, práctica y redacciones.

Abre `index.html` (o la página de GitHub Pages). Tus marcas, palabras y redacciones se guardan en el navegador; usa «Copia de seguridad» en la página de inicio para moverlas entre dispositivos.
